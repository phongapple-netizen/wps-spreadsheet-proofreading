# 文字版界面对齐（2026-10-05）

只读对照本机文字版 `ui/taskpane.html`、`ui/taskpane.css`、`js/taskpane.js` 和模型客户端；文字版仓库未修改。

## 差异与修复

| 项目 | 表格版原状 | 本次对齐 |
| --- | --- | --- |
| 模型目录 | `/provider` 返回公共目录，重开后只显示当前配置 | 使用文字版的 `/config/providers`，读取本机配置模型 |
| 列表保存 | 没有目录缓存 | 按提供商、服务地址缓存；重开及切换提供商后保留模型列表 |
| 模型检测 | 手动点击后才填充列表，数量提示不清楚 | 打开设置检测已运行的 OpenCode 并读取模型，显示数量；不自动启动服务或发送校对文本 |
| 当前模型 | 刷新可能替换目录外的手动模型 | 保留当前模型，并标记“当前配置”；下拉与手动输入均可用 |
| 问题卡片 | 地址、徽标、多栏对比和所有操作同时展开 | 套用文字版的卡片结构与既有样式：紧凑标题、红绿文本对比、点击展开、错误分析、更多操作菜单 |
| 操作目标 | 点击卡片定位单元格 | 保留定位；修正、忽略、保存规则与菜单点击分别处理；支持键盘展开定位 |
| 错误反馈 | 状态被隐藏 | 保留上一轮修复，让错误和内容变化提示可见 |

表格必须保留工作表、单元格地址与选区范围；文字版使用段落与修订定位，这些宿主行为没有搬入。
保留现有表格导出功能、连接测试和现有安全写回检查。每次校对选择一个模型，模型列表提供多个可切换选项。
缓存不写入密码、密钥或外部服务地址；更换服务地址不会误用旧目录。

## 验证

本机 OpenCode 1.18.34 实际配置目录：35 个模型。
当前工作区 `npm test`：82 项通过，0 失败。
无界面浏览器以 360 像素宽面板加载真实 HTML/CSS/JS，验证模型选择、重载保留列表和所选模型、问题卡片展开与定位回调、更多操作菜单、无横向溢出、无页面脚本错误。
卡片验证使用模拟问题与定位回调；没有在本轮替代 WPS 真机选区、定位或写回验收。
WPS 中需重新载入插件页面才能使用更新；本轮没有关闭用户工作簿或重启 WPS。
