## 修复与安全边界

表格模型客户端按文字版保留标准工具定义，去掉 message.tools 覆盖。
保留工具执行前的通配审批要求及回显校验；客户端从不批准权限；发现本会话待审批立即中止；审批接口失败也中止；返回 tool 类型部件也拒绝结果；失败后 abort 并 delete 会话。
仅提取最终 text 部件，不把 reasoning 混入校对 JSON。

修复后的原表格客户端再次真实调用 MiMo，正确返回 B2、B3、B4 三条问题；清理后的会话查询为 404。
