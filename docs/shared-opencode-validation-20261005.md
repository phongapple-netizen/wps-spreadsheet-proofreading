# 共享 OpenCode 适配与验证（2026-10-05）

## 改动范围

只修改表格版。文字版代码、安装器及注册保持原样。本轮未新增安装包，也未合并 main。

- 新配置默认使用 4096；旧 4097、自定义地址、模型和缓存保留，用户在设置中手动切换。
- 默认本机 4096 请求经过网页服务同源 `/api/opencode` 代理；非默认接口保持原有直接连接。
- 代理固定上游 `127.0.0.1:4096`，不跟随重定向，不接受任意 URL；校验 Host/Origin、随机窗格标识、认证绑定、方法及路径。请求上限 2 MiB，响应上限 16 MiB，有请求和上游总超时。
- 创建会话强制全部工具审批；文本消息固定 agent 和安全 system，不转发文件、工具选项或用户指定 agent。没有工具批准接口、文件接口、命令接口或全局修改接口。
- 会话归属按窗格标识和认证绑定；审批列表过滤到本窗格。中止/删除只能操作本窗格创建的会话，不能干预文字版会话。客户端发现工具审批/工具结果即取消并清理；断开进行中的模型请求时代理也尝试中止该会话。
- 先检测健康和版本，再检测占用。另一个客户端启动尚未就绪时短暂等待；自己的启动进程失败退出时重新探测另一方是否已经成功。没有跨项目原子锁，极短时间内可能产生一个绑定失败的启动进程，最终复用成功监听者；不会杀掉另一个客户端的进程。
- 自己启动时绑定回环，固定 4096，允许 3891/3892（及当前合法调试来源），与已发布文字版一致采用普通模式（不传 `--pure`），独立后台运行。成功后退出网页服务不结束共享进程；仅失败启动可结束自己的进程。

## 当前边界

- 现有 4097 不自动迁移或停止；需要用户选择共享地址。共享进程不会随任一表格窗格关闭，需用户明确管理其停用。
- 文字版启动的共享实例保持其原有配置；表格版不修改全局配置。两端可能共用 provider/模型额度与并发资源，本轮没有新增全局调度。
- 代理归属记录仅在当前网页服务内存中。重启后不接管旧会话，进行中的请求应取消重试；意外进程终止可能留下待清理会话，未建立持久后台清理机制。
- 复用要求当前 OpenCode API 支持且回显本会话全部工具审批；不满足即中止，不能降低安全门。
