# WPS 表格校改

独立的 WPS 表格（ET）校对加载项，当前版本 **0.2.0**。界面与通用校对能力参考 WPS 文字版，单元格读取、定位、写回和撤销采用表格宿主适配。文字版仓库只用于查看，没有修改。

## 已实现

- 尽量还原文字版任务窗格：校对/改写切换、深度增强、问题卡片、分类筛选、处理历史、设置页面、规则中心和诊断面板。
- 校对选区（含多区域）、当前工作表或整个工作簿；跳过空值、数字和公式，合并单元格只读取左上角一次。
- 长单元格分段、并发批次、限流重试、取消和部分结果保留；深度增强增加跨单元格一致性复核。
- 单条定位、修正、忽略、自动定位下一条；同一单元格多条建议根据已应用修改调整位置，冲突建议标为需重查。
- 处理历史和撤销；撤销前再次核对完整单元格内容，避免覆盖后来编辑。
- 本地规则校对、规则包启停、自定义替换/正则/提醒/AI 复核规则、规则测试、导入导出、由建议创建规则。内置中文写作、党政公文、工作安全规则包。
- 一键修正仅处理白名单内的安全内置规则；AI 建议与需复核项逐条确认。
- 单个文本单元格改写：要求输入、预览、重新生成、取消、替换和撤销。数字等事实变化会阻止替换；其他风险需要勾选确认。
- OpenCode、Ollama、OpenAI 兼容接口；独立配置、模型列表、手填模型和连接检测。本机 OpenCode 可以通过调试服务启动。
- JSON 结果导出、可选耗时日志。历史和日志保留在本次窗格会话中。

## 本地调试

需要 Node.js。运行与测试脚本使用 Node 内置模块，不需要先安装开发依赖。

```bash
npm test
npm run debug
```

`debug` 在 **http://127.0.0.1:3892** 提供加载项，并向本机 WPS 的 `publish.xml` 注册独立的 `et` 项。已有文件先备份为 `.bak`（重名时递增后缀）；其他加载项条目保留。启动后重新打开 WPS 表格，从功能区打开校改任务窗格。

只查看网页、不注册加载项：

```bash
npm run debug:server
```

浏览器访问 `http://127.0.0.1:3892/ui/taskpane.html` 可以检查界面。真正读取选区、定位和写回需要 WPS 宿主。

`npm run build` 仍使用 `wpsjs build`，需要先 `npm install`；构建安装包及各平台发布尚未做实机验收。

## 模型设置

OpenCode 默认使用 **http://127.0.0.1:4097**，与文字版常用服务端口分开。先在本机安装并配置 `opencode`，再点击“检测并读取模型”。调试服务仅负责启动本机 4097 服务，不负责安装或登录。也可以手工启动：

```bash
opencode serve --hostname 127.0.0.1 --port 4097 --cors http://127.0.0.1:3892
```

OpenCode 模型填写 `provider/model`。Ollama 默认 `http://127.0.0.1:11434`，需自行启动并下载模型；OpenAI 兼容接口需填写地址、模型和可选 API Key。

设置按服务商分别保存；密钥、密码和外部接口地址仅保留在内存，重开窗格后需要重新填写。OpenAI/Ollama 连接检测会发送简短模型请求，可能产生调用费用或本地计算。

## 数据与写回边界

- 每次最多扫描 20,000 个位置、50,000 个文本字符；选区最多 100 个区域。超限明确提示，缩小范围后重试。
- 常规校对按最多 2,500 个文本字符、30 个片段分批；长单元格按原文偏移拆分。并发可设 1–4。
- 改写要求选区只包含一个文本单元格，最多 5,000 字符。
- 保留空格和换行；每次修改或撤销前核对工作簿、工作表、地址、完整原值和公式状态，写后复核结果。
- 无法确认公式状态、原文已变化、切换到其他工作簿、建议会形成公式时拒绝写入。
- 结果随完成的批次更新。目前没有模型逐字流式输出，也没有文字版的文档修订模式；表格采用单元格写回和会话内撤销。

## 真机验收

自动测试使用模拟宿主和网络；浏览器检查验证界面与交互。**真实 WPS 的注册、选区 API 和写回仍需真机调试。** 建议先用测试工作簿：

1. 选中文本、数字、空白和公式混合区域，检查送审范围与定位。
2. 测试多区域选择、合并单元格、当前工作表和整个工作簿；两个工作表都包含 A1 时检查目标是否准确。
3. 打开“仅本地规则”，用重复标点测试一键修正与历史撤销。
4. 同一单元格包含多条问题、首尾空格、换行和长文本时逐条修正，再按逆序撤销。
5. 校对中取消；修改原文或切换工作簿后尝试旧建议，确认不会覆盖新内容。
6. 切换三个模型服务商，检查配置独立；测试错误地址、错误凭证、手填模型与模型列表。
7. 开启深度增强检查数量不一致；改写数字或日期时检查风险阻止，安全改写检查替换与撤销。
